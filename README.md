# Customer Segmentation Using Clustering

## About the Project

This project groups customers into different segments based on their purchasing behaviour.

K-Means clustering is used to find customers who have similar characteristics.

## Objective

The main aim of this project is to group customers into useful segments so that businesses can understand their customers better.

## Dataset

The dataset contains information such as:
- Age
- Income
- Spending Score
- Membership Years
- Purchase Frequency
- Last Purchase Amount

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Algorithm Used

- K-Means Clustering

## Steps

1. Loaded the customer dataset
2. Checked the data
3. Removed the unnecessary ID column
4. Selected the required features
5. Scaled the features
6. Used the Elbow Method to find the number of clusters
7. Applied K-Means clustering
8. Assigned customers to clusters
9. Studied the different customer groups
10. Created graphs to visualize the clusters
11. Saved the K-Means model

## Result

The customers were divided into different groups based on their income, spending and purchasing behaviour.

## Conclusion

This project shows how clustering can help businesses understand different types of customers and plan better marketing strategies.
